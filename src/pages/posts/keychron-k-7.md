This is a [Keychron K7](https://www.keychron.com/products/keychron-k7-pro-qmk-via-wireless-custom-mechanical-keyboard) with brown switches and a custom black keycap set (apparently discontinued).

I've been using it for filming outdoors since it's slim and lightweight, which makes it ideal for that. The layout is 65% ANSI, which is mostly compatible with Apple's keyboards, so it feels natural. The typing sound isn't perfect, but I'm happy with it.
